# Raised-Type Bible Accessibility Portfolio

This repository contains my INFOST4019 project portfolio for **AI for the Arts and Humanities (B)**.

## Main notebook

- `tactile-bible-portfolio.ipynb`

## Project object

This project focuses on an English New Testament printed in 1850 and held by the University of Glasgow Special Collections.

- Object: *Bible. New Testament. English. Authorized*
- Format: Printed in high relief for use by blind people
- Shelfmark: Sp Coll RF 256

## Project overview

The project explores how a nineteenth-century raised-type Bible can challenge a visual-first understanding of digital accessibility.

It asks what happens when a book designed to be read by touch is mainly encountered through images, catalogue records, or screens. The notebook considers what digitisation can make available, what it cannot fully preserve, and how a speculative tactile reading station might help communicate touch-based access to a general audience.

## Human-AI collaboration

Generative AI was used as part of the creative process, not as historical evidence.

In this project, GPT was used to generate speculative prototype images for a Dynamic Tactile Reading Station. ElevenLabs was used to create a short AI-generated audio example. These outputs were reviewed, selected, and edited through human interpretation.

The final project concept, historical framing, written interpretation, ethical limits, and selection of outputs were human-directed.

## Notes on code

The Python code in the notebook is a small demonstration of how a selected passage could be prepared as a word-by-word reading sequence. It does not build a working tactile display or engineering system.

No external Python libraries are required for the code demonstration.
